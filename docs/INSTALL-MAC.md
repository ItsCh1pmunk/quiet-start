# Mac 上安装 Quiet Start

适用：macOS 上支持 Manifest V3 的 Chrome 104 或以上版本，建议使用当前稳定版。安装无需命令行、开发工具或账号。

## 一、保留扩展文件夹

从 [GitHub Releases](https://github.com/ItsCh1pmunk/quiet-start/releases/latest) 下载 `quiet-start-1.0.0.zip`，解压得到 `quiet-start` 文件夹。把它移动到长期保留的位置，例如 Finder 中「文稿 → Chrome 扩展」。进入该文件夹应直接看到 `manifest.json`、`newtab.html`、`styles.css`、`src` 和 `assets`。如果使用 GitHub 的 Code → Download ZIP，解压目录通常叫 `quiet-start-main`，同样选择直接包含 `manifest.json` 的这一层即可。

Chrome 会直接从此位置读取扩展，安装后请勿删除或移动文件夹。整个工程无需联网下载资源。

## 二、加载到 Chrome

1. 打开 Google Chrome。
2. 地址栏输入 `chrome://extensions`，按回车。
3. 打开右上角「开发者模式」。
4. 点击左上角「加载已解压的扩展程序」。
5. 在文件选择器中选择 `quiet-start` 文件夹，点击「选择」。请选包含 `manifest.json` 的这一层。
6. 页面出现「Quiet Start · 收藏夹起始页」卡片，且开关已启用，即已安装。
7. 按 `⌘ T` 打开新标签页。若 Chrome 提示此扩展更改了新标签页，请保留此更改。

不要直接双击 `newtab.html`：普通网页环境无法访问 Chrome 书签。此交付包不是商店签名的 CRX，应该使用「加载已解压的扩展程序」安装。

## 三、选择收藏夹

1. 点击新标签页右上角的文件夹按钮，或右下角的自定按钮。
2. 在「书签文件夹」下拉框中选择来源。
3. 默认按文件夹分组，所有深层书签都包含在内。想像 Finder 一样逐层进入文件夹时，关闭「按文件夹分组」。
4. 拖动「图标大小」和「每行数量」。修改即时生效，设置自动保存。
5. 点击面板右上角 `×` 或按 `Esc` 关闭。

书签顺序沿用 Chrome。按 `⌘ ⌥ B` 打开书签管理器；也可以在地址栏输入 `chrome://bookmarks`。在管理器中添加或调整书签，新标签页会自动更新。

## 四、外观与图标

- 系统设置 → 外观 → 浅色 / 深色 / 自动。起始页跟随浏览器报告的系统主题。
- 如果 Chrome 的外观设置固定了主题，先检查 Chrome 设置 → 外观。
- 未访问过的网站可能没有缓存图标，显示通用图标属于正常情况。正常访问网站后，再刷新新标签页；扩展不会为了图标主动访问网站。
- 需要统一的离线外观时，开启「仅使用字母图标」。

## 五、更新、禁用和卸载

更新：用新版本覆盖保留目录中的文件；打开 `chrome://extensions`，点击本扩展卡片的重新加载按钮，再新开标签页。维持目录位置可保留原扩展 ID 和本机设置。

临时恢复 Chrome 新标签页：在扩展管理页关闭本扩展开关。

卸载：点击扩展卡片的「移除」。扩展自己的本机设置将被清除；Chrome 书签不会被修改。之后可删除文件夹。

## 常见问题

- **新标签页仍是其他页面**：检查本扩展是否启用，以及是否有其他同样替换新标签页的扩展。禁用冲突扩展后新开标签页。
- **没有书签**：在设置中选「全部书签」，确认书签是否在另一层文件夹，或检查是否打开了另一个 Chrome 用户配置。
- **提示无法读取书签**：点击「重试」。若仍失败，在扩展管理页重新加载扩展后再打开新标签页。
- **来源文件夹被删除**：自动回退至当前可用的书签栏；请重新选择来源。
- **提示找不到 manifest**：所选目录层级不对，选择直接包含 `manifest.json` 的文件夹。
- **开发者模式不可用**：工作或学校管理的 Chrome 可能禁止加载本地扩展，需要由设备管理员按组织规则处理。
- **隐身模式**：本项目面向普通配置的新标签页；Chrome 的隐身新标签页与扩展限制由浏览器决定，不承诺替换。
